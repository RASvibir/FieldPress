How to run the newsroom

This sheet is for the person who owns FieldPress. It is not a public help page. Do not link it from the launch screen, social posts, or README. Print it or save the HTML and keep it with your keys.

What this product is

FieldPress is a pocket newsroom. A reporter captures notes in the field, then produces three outputs: an article, a social post or thread, and a podcast script. Gemini drafts those outputs. Live public headlines (related, national, global) are pulled in so the drafts can land with an audience that is already paying attention.

  • Public surface: https://fieldpress-dusky.vercel.app — Open / Install / Copy link.
  • Newsroom: /app — stories, produce, edit, distribute.
  • This manual: /admin and /admin-manual.html — operator only.

Daily desk

  1. Open the app. On a phone, install it to the home screen so it launches without the browser chrome.
  2. Create a story with a working headline. The headline is the search seed for public trends, so make it specific.
  3. Add field notes: what you saw, names you can stand behind, quotes, times, places. Thin notes produce thin drafts.
  4. Optional: import a mobile dispatch. First line is the title. Following lines become notes.
  5. Tap AI PRODUCE. Wait. It scans live headlines, then writes article, social, and podcast drafts.
  6. Read the Trend Desk first: Why now, audience, relatable / national / global hooks. These are assignment notes, not facts you witnessed.
  7. Open each draft. Cut anything the notes do not support. Verify names, counts, and any public-context claim before you publish.
  8. Distribute: copy, download markdown, native share, or open a compose window for X, Threads, Bluesky, LinkedIn, email, and the rest.

Trend desk — how generation actually works

Produce is not “write a recap of my notes.” It is “turn these notes into the strongest news product by connecting them to what the public is already talking about.”

LayerJob
Field notesOnly source of original facts, quotes, names, counts, and on-scene detail. The model must not invent these.
Live headlinesGoogle News related search (last 7 days), US national, world, plus Wikipedia most-read as a public-attention proxy.
Trend DeskWhy now, audience, and 3–6 hooks labeled relatable / national / global, with a product hook for article, social, or podcast.
DraftsArticle nut graf, social open, and podcast cold open should use public conversation for framing, then drop into the reporter’s scene.
Public headlines are context, not sourcing. Never let a draft present a national or global story as something the reporter observed. If a trend is only loosely related, drop it.

Make the notes earn the trend

  • Relatable: one human scene, everyday stakes, the question a non-expert would ask.
  • National: institutions, policy, who holds power, what the country-level coverage is missing.
  • Global: a parallel or knock-on that keeps an overseas listener in the episode.

Trend Desk on the story page is stored in this browser. The three drafts are stored in Postgres. If you switch devices, produce again or copy the drafts.

Outputs

ModeWhat good looks like
ArticleLede (scene or why-now), nut graf that places the reporting in public conversation, body from notes, kicker that looks forward.
SocialOpen with a hook people already recognize, then the exclusive field detail. Real conversation hashtags, not generic #News.
PodcastCold open poses the national/global question, then the scene. Segments, outro, show notes that label “this week’s conversation” as public context.

Keys and environment

Never commit .env. Copy .env.example.

VariableRole
DATABASE_URLNeon pooled Postgres for the API.
DATABASE_URL_UNPOOLEDDrizzle push / schema.
GEMINI_API_KEYRequired for AI Produce. Without it, produce returns 502.
GEMINI_MODELDefault gemini-3.5-flash.
GEMINI_TREND_SEARCHSet to 1 to add a live Google Search assignment brief before drafting. Off by default so quota is spent on the actual drafts. RSS headlines still run.
PORTLocal API, default 3000.

Same names belong in Vercel project env for production. After changing env, redeploy.

Local and ship

  1. pnpm install then pnpm db:push if the schema changed.
  2. pnpm dev — API at http://localhost:3000, Vite newsroom at http://localhost:5173 (use 5173 while iterating on UI).
  3. pnpm start — builds desktop into the API and serves everything on 3000.
  4. Health: GET /api/healthz.
  5. Mobile: pnpm dev:mobile. On a real phone set EXPO_PUBLIC_API_URL to the LAN IP, not localhost.
  6. Production: vercel deploy --prod --yes from the repo root. Public URL: https://fieldpress-dusky.vercel.app.
Produce can take 10–40 seconds. Headline fetch is fail-soft. Gemini 429/503 is retried twice. If quota is exhausted, drafts will still fail until the key has budget again.

When it breaks

SymptomCheck
Produce 502, “GEMINI_API_KEY is not set”Local .env or Vercel env. Restart after setting.
Produce 502, 429 / quotaGemini billing and rate limits. Leave GEMINI_TREND_SEARCH off.
Produce 502, 503 high demandWait and retry. The server already retries twice.
Empty Trend Desk, drafts existTrend Desk is browser-local. Drafts are in the database. Produce again on this device or open the drafts.
Phone cannot produceEXPO_PUBLIC_API_URL must be the machine LAN IP. Phone and computer on the same network.
Install button does nothingSafari on iPhone: Share → Add to Home Screen. Safari on Mac: File → Add to Dock.

Do not

  • Do not publish unverified names, casualty counts, or quotes.
  • Do not treat Trend Desk headlines as reporting from the scene.
  • Do not put this manual, keys, or operator URLs on the launch page.
  • Do not commit .env, .vercel, or API keys.
  • Do not brand FieldPress as another studio’s product. This newsroom stands alone.

One-page cheat sheet

Headline with a place or subject → notes with scenes and attributable quotes → AI PRODUCE → read Why now / audience / three-scale hooks → edit article, social, podcast → verify → Distribute → delete nothing until the package has shipped.
